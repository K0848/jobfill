# 网申跟进表统一更新入口

## 范围与调用

适用于本机 Windows 中多个网申聊天共用一个 `.xlsx` 文件。仅用 Python 标准库，不要求安装 Excel 或重新导入／导出整张表。网页各自绑定 tabId 并行填写；更新跟进表时通过此入口串行执行。

工作簿由用户或被忽略的本机个人工作流指定，示例为 `C:\path\to\tracker.xlsx`，工具要求显式传入，测试不得省略后误写正式文件。先把下列内容保存为 UTF-8 JSON（示例不是待投递事实）：

```json
{
  "company": "示例公司",
  "job": "2027届 AI产品经理",
  "url": "https://example.com/jobs/123",
  "completed": true
}
```

```powershell
python -B tools/update-job-tracker.py --workbook 'C:\path\to\tracker.xlsx' --request-file '<临时目录>\tracker-request.json'
```

请求只能包含上述四项；公司、岗位、HTTP(S) 职位链接须有来源，`completed` 必须为布尔值。使用实际可用的 Python 路径；运行环境缺失时先定位，不能临时改用不带锁的写表方式。

## 业务与写入边界

- 自动查找含公司、岗位、链接、当前状态表头的唯一工作表，不假定列号。唯一岗位才更新；重复候选或无法识别结构时报错。
- 网页填写完成并读回核对后传 `true`：新记录／空状态写“筛选中”，表示等待用户核对后提交，不表示已提交；仍有必填缺失或未成功写入则传 `false`：先记岗位，状态留空。
- 只写公司、岗位、链接及空状态；旧非空状态保留，不把面试等进度降级。新行继承原格式并续接序号。其他列不补内容，不清空旧备注、日期、结果，不回填历史记录。
- 链接单元格显示完整网址并写原生超链接。有唯一 `jobAdId`／`jobId` 查询参数时按站点与 ID 去重；其他链接保留有业务含义的路径和 fragment，剔除明确的跟踪参数。匹配链接但公司或岗位名称冲突时拒绝覆盖；无链接旧行只在公司与岗位唯一匹配时补齐。不凭公司名称覆盖不同岗位；无法取得明确职位链接时不调用此入口。
- 工具从 ZIP 内仅补丁修改目标工作表及其超链接关系，其他部件保持原字节。未知工作簿结构安全停止，不重建原文件。当前不自动扩展 Excel 表对象（Table），不承担任意工作簿修复或公式重算；普通单元格区域、已有样式与验证是本次支持范围。

## 并发、占用与恢复

1. 解析规范绝对路径后，取得按该路径命名的 Windows 互斥锁；默认最多等待 30 秒（`--lock-timeout` 可设 0—300 秒）。进程中断时操作系统释放锁，不生成需要删除的锁文件。
2. 取得锁后读取最新原文件。检测 Excel 的 `~$` 占用标记及写句柄冲突；构建过程中保持拒绝外部写入的读句柄。
3. 在同目录生成临时工作簿，验证 ZIP、字段及保存结果；替换前检查源文件仍与读取版本相同，再替换并在锁内读回。临时文件使用后清理，不默认留备份。
4. 所有聊天必须使用同一入口和同一路径，不能绕开锁。锁保证本机同 Windows 会话的这些聊天互斥，不是跨机器文件同步方案。非协作程序允许删除共享并在最后检查与替换之间写入的极小竞态无法完全阻止；人工编辑时应先关闭工作簿再运行。

退出码 0 返回 JSON，包含 `sheet`、`row`、`action`、`status`、`company`、`job`、`url`、`readback`。仅在读回匹配后报告记录完成。退出码 1 返回错误：保留网页成果，说明跟进表尚未确认完成；先核对实际记录，再解决占用／结构／身份问题后通过同一入口重试，不整单重填，不用无锁工具兜底。

## Skill 文件入口

公开 Skill 位于 `.agents/skills/fill-job-application/SKILL.md`。本机私人流程独立维护在 Git 忽略的 `data/personal-workflow.md`；本机 `.claude`、`.codex`、`.workbuddy-ai` 的入口共享此文件。`tools/convert-skill-links.ps1` 在具备权限时将这三个本机硬链接转换为文件软链接，目标根据脚本所在仓库自动定位，不依赖旧目录。

全新克隆先运行 `node tools/init-local.cjs`，再编辑生成的本机资料和授权。之后在仓库根目录运行 `./tools/convert-skill-links.ps1`；只读检查添加 `-CheckOnly`。缺失入口会新建，已有同源硬链接会转换；转换前先验证临时软链接，权限不足时不删除旧入口，不修改开发者模式或执行策略。实际转换须在具备权限的 PowerShell 中完成。

## 验证入口

`python -B tests/test_job_tracker.py` 使用临时测试工作簿验证真实跨进程写入、重复请求、字段／超链接／格式保留及失败边界。真实网申网页的地区控件和自我评价行为仍需下一次授权填写时验收，测试不操作招聘页面或正式工作簿。
