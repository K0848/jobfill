# 本机个人配置

本文件复制到 `data/personal-workflow.md` 后仅供本机使用，不提交 Git，只维护路径、偏好与已确认授权。唯一执行流程为仓库根目录的 `.agents/skills/fill-job-application/SKILL.md`；从本文件或其 Skill 别名进入时，先定位包含 `tools/` 与该共享 Skill 的仓库根目录，读取共享流程后执行。已读配置或流程不重复加载；不要把执行步骤复制进本文件，也不从示例推定授权。

- 个人资料：`data/profile.md`（相对仓库根目录）；先将虚构示例替换为本人确认信息。
- 招聘页面：使用当前会话用户指定的 URL，不复用示例 URL 或旧 tabId。
- 投递跟进表绝对路径：未配置。
- 模块保存、下一步与预览授权：尚未授权。
- 附件上传授权：尚未授权。
- 自动更新跟进表授权：尚未授权，使用前确认。
- 状态口径：使用更新工具时，填写完成且读回后记“筛选中”，不代表已提交；是否采用须由本人确认。
- 工作城市、面试城市、薪资及招聘来源等通用偏好：尚未确认；本次申请选择不得自动提升为通用偏好。
