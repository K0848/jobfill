# 网申填写

以用户指定的资料和当前页面为依据，在授权范围内核对、填写并读回；先完成可执行部分，再集中交接缺失与待确认项。仓库根目录包含 `tools/` 与 `site-hints/`；从仓库根目录执行命令。用户只要求检查时保持只读。

## 唯一流程与本机配置

- 本文件是网申执行流程的唯一维护位置；所有本机 Skill 入口均引用本文件，不另存一套流程。仓库根目录以同时包含本文件、`tools/` 和 `site-hints/` 的目录为准，不把 Skill 别名所在目录当作工具工作目录。
- 如存在 `data/personal-workflow.md`，读取其中的本机路径、个人偏好和已确认授权；该文件只存配置，不复制执行步骤。从本机配置入口转入本流程时，复用本轮已经读取的配置，避免反复加载。未配置时按当前会话授权执行，不将示例中的值当作真实资料或授权。
- 相对 `profilePath` 以仓库根目录解析。执行工具前切换到该目录；从外部目录调用时，同时提供工具绝对路径与资料绝对路径。开始时说明实际资料路径，同一申请不静默切换来源。
- 真实资料、偏好、凭据、附件和运行报告保留在 Git 忽略的 `data/` 或项目外。公开提交复用本流程与虚构配置示例，不制作另一份脱敏流程；提交前检查实际差异与文件清单，已跟踪文件不受忽略规则保护。

## 事实和权限

- 确认用户指定的 Markdown 路径和目标页面；没有资料或目标时询问，不猜测个人事实。资料格式见 `examples/profile.example.md`，真实资料与运行产物不要提交或分享。
- 核对已有值与空字段：按字段语义和经历的学校、公司或项目 `identity` 对应资料。来源明确的已有字段也纳入计划，不因非空就跳过；检查解析错位、截断、日期精度、单位及岗位匹配。现值正确则保留；冲突、来源不明或身份不唯一时保留现值并列为待确认。只有用户授权且来源明确的更正才能覆盖已有值；缺少依据只能记为未核对。
- 普通事实值须与 `profile.*` 对应字段一致；会话确认、站点同义选项映射或由资料派生的值使用 `user.*`，并提供非空 `sourceText` 说明依据和推导。资料中已确认但解析器未支持的补充内容同样使用 `user.*`，不伪装成其他经历组。缺少依据不填写；不得把不同字段、记录或日期精度混用，不能凭常识补事实。
- 不为本流程固定模型或推理强度，遵从用户的设置。模块保存、保存并跳转、下一步、预览和附件上传，按当前指令或本机配置中已确认的授权执行；已有授权不逐次询问。未授权的外部操作先保留，完成独立内容后集中交接。不默认修改长期个人资料或跟进表。最终投递、提交申请、发送邮件仍须本次明确授权；验证码、OTP 和缺少事实依据的声明交由用户处理。
- 岗位定制不自动启动网申；用户要求填写后，沿用本次已确认的公司、岗位、完整 JD 和定制附件，不重复选择。基础事实取个人资料，定制职责和能力表达按学校、公司或项目身份匹配，用 `user.*` 与 `sourceText` 记录 JD、附件路径、原文和取舍；不自动写回长期资料或另建定制副本。跨聊天恢复依已确认材料和页面现状，不凭修改时间认定确认或投递状态。
- 自我评价先读完整 JD，判断岗位需要怎样的人，再从已确认经历中提炼最相关的 2—3 项能力；围绕相关基础、做事方式及协作或学习特点组织简短自然段，按岗位和证据取舍，不机械套结构。经历仅用于内部核实，不复述公司、项目、过程和指标，也不把自我评价写成技能清单。技术名词仅在能说明岗位匹配时保留；组织协调、细致、学习等特点也需依据，不能用空泛形容词替代技术清单。
- 自我评价的表述强度须与证据一致：数据处理与结果核验不自动拔高为业务洞察或分析决策，参与不写成主导，岗位要求不当作个人能力；不新增行业经验、行业热情或职业意愿。默认一个简短自然段，按页面字数限制取舍，不凑长度或强加“期待加入”。成稿检查岗位匹配、是否仍像技术或项目清单、每句话的依据与强度。`profile.basic.selfEvaluation` 仅作素材，已有岗位定制版本先核对，不用通用版本覆盖；缺 JD 只暂停该项。使用 `user.jobSpecificSelfEvaluation` 和 `sourceText` 记录 JD、个人资料及改写依据；已授权填写不逐句重复确认。
- 技能、特长、职责可按字段摘取、压缩已有资料，不新增事实、提高能力等级或改变职责范围；去掉内部备注、资料标题和无关网址，项目链接填对应链接栏。改写使用 `user.*` 记录原文及删改依据，不冒充资料逐字内容。
- 偏好按当前指令、本次申请确认、明确通用偏好的顺序使用；已确认事项不重复问，本次城市选择不自动升级为长期偏好。长期资料写回仍须明确授权。

## 缺失与待确认的处理时机

- 先核对资料中已确认的补充段落和会话确认；字段缺失、冲突、候选歧义、附件待选或偏好待定时，保留原值或留空，记入本轮待办，不立即发起用户输入或逐项确认。记录模块、字段、必填性、现值、原因和候选即可，不另建持久化清单。继续所有可安全访问、已有依据且不依赖答案的内容；缺少某条经历的必填信息只暂停该条。保存和导航仍以实际授权为限，不为跳过校验猜填、写占位内容或丢失未保存的结果。
- 已明确没有或不适用的内容按事实处理；未在资料中提及不能推断为“无”。缺来源的选填项默认留空，末尾合并提示并交给用户自行补充；必填缺失、实质冲突和新的个人取舍集中询问。
- 可执行部分完成并读回后，一次交接已完成内容、实际保存状态、留空选填项及待回答或待本人处理事项。问题列明模块、字段、所需事实或选择、可用候选及是否阻挡后续；同一事实只问一次。用户选择自行填写时直接交接，不反复追问。
- 只有阻塞项确实使后续步骤无法继续，且当前可独立处理的内容已做完时，才提前集中询问已知阻塞项；登录、验证码等必须本人处理且阻断后续时同样交接。用户回复后只恢复受影响项，不重填已完成项；后续新发现的问题仍集中处理。最终保存、提交等操作的授权边界保持不变。

## 操作

1. 读取本机配置（如有）和对应资料，使用 Huashu Chrome 查看当前标签和页面，集中观察字段、已有值、必填性、控件及所属记录。优先复用匹配标签，仅无匹配时新建；相同 URL 有多个标签时绑定确切 `tabId`。先确认桥接可用；连接失败时停止该页面操作。缺失项先记录，继续确定项。
2. 依据当前观察及资料生成 `plannedFields`。每项标注 `label`、`sourceKey`、`value`、`matchMode`、可重新定位的 `selector` 或 `find`、普通字段的 `tagName`／`type`、复杂控件的 `widgetKind` 和需要时的 `recordIdentity`；汇总时注明 `executionPath`（`cli`／`direct`）及简短 `routeReason`。同一 `sourceKey` 不重复用在多个计划字段。页面变化时只重新观察受影响区域。
3. 普通字段和当前页面已验证的控件优先经批量 CLI 执行；用户明确要求直接操作时遵从。不要由 Agent 逐字段重复调用浏览器工具，CLI 内部仍需进行必要的现值和读回检查。将请求 JSON 放在本机受保护的位置，不把资料值或完整请求拼到命令行。请求结构见 `examples/request.example.json`，必须替换为当前页面、资料路径和实时观察结果。

   ```powershell
   node tools/jobfill-batch-cli.js --request-file <临时目录>\jobfill-request.json
   ```

   始终设置 `snapshotHint.tabId` 固定目标。CLI 对目标标签、来源、现值和读回进行检查；如需更正已有值，提供 `authorizedReplacement: { expectedCurrentValue, sourceText }`，记录刚读到的原值、更正授权与依据。写前现值变化则停止该项重新核对。直接路径遵守相同要求，不反复覆盖或直接调用内部执行器绕过保护。
4. 对 CLI 不支持或已知不稳定的控件，直接使用授权的浏览器操作，不要求先失败一次。未知控件只补读必要结构与候选，不挨个试遍驱动。工具报错先核对页面：已与目标一致即保留；仍为空且来源明确时当轮采用有效路径继续。只有原因明确、修正后有成功依据才局部重跑一次，不重跑成功项。目标标签关闭、连接失效、权限受限或无法唯一重绑定时停止受影响项并报告 `pending`／`blocked`。每个 Agent 显式绑定自己的 `tabId`；不同网申聊天可并行，本页 CLI 与直接操作顺序执行。填写期间不修插件或展开架构研究。
5. 普通文本批量完成后集中读回，复杂控件选择后核对实际值；操作已返回可信读回时复用，无新改动或错误不重复验证。已获模块保存授权时，核对后保存能独立保存的模块，并检查保存提示或持久化读回；必填缺失导致保存失败时保留成果，如实交接，不报告整单完成。
6. 已获跟进表授权时按下节更新并核对；然后合并结果，一次交接已核对正确、已更正、已填写、实际保存状态、留空选填项、待回答或未验证项，以及执行路径和实际恢复情况。区分页面填写、网站保存和最终提交，最终动作仍由用户确认。只生成本轮必需的临时文件，确认无后续用途后清理。

可按站点参考 `site-hints/` 中的控件说明，但应以当前页面为准。不要将历史示例当成对当前页面的验证。

## 地区选择

现居地、籍贯、户口、学校、实习城市按对应事实填写，工作和面试城市分别按对应偏好选择。站点只到省或市时按其粒度映射。先读取完整候选再按已确认规则排序，不能把“都在广东”当作具体先后依据；仅确认岗位唯一所在地时直接匹配，涉及迁居等意愿且无已确认偏好时，保留该项并按上节集中询问。

打开字段、逐级选择、完成控件内部“确定”，关闭弹层后读回真实选中值，检查后一级联动字段未被清空。搜索文字和候选高亮不等于选中；控件内部确定属于字段填写，不等于网页保存或提交。

## 复杂控件与附件

- 使用 Huashu 真实 `click`／`type`／`fill`，同步 `eval` 仅作只读探测。当前桥接不等待页面 Promise，不能把页面内异步驱动返回的 `{}` 当作执行完成。
- 复杂弹层必须找到唯一候选并读取组件实际值；候选重复、无匹配、弹层未打开或读回不一致时保留 `pending`／`write_unverified`，不按顺序猜选或重复点击。坐标操作前确认弹层稳定，输入框文字不等于完成选择。
- PrimeNG（Angular、`ui-*`）下拉用真实点击打开面板、同步定位唯一候选、真实点击并读 `.ui-dropdown-label`；单选先核对标签与组内状态，再点击 `.ui-radiobutton-box`；日期检查面板年月、高亮日与显示值确实进入组件模型。仅本轮新写入的日期仍未生效时，清除本轮输入并记录未验证，不清除用户原值。
- 已验证的 Moka 结构中，最高学历、语言掌握程度曾需真实操作；同结构优先直接处理，直到有当前版本修复证据，不外推所有 Moka 控件。站点说明参考 `site-hints/`，以当前页面为准。
- 附件已有本次确认的绝对路径时，按上传授权操作，并核对响应与页面文件名、尺寸或预览；没有确认路径时保留候选，完成其他内容后集中交接，不猜选来源不明的图片。

## 奖励描述

- 保留获奖学年、多次或连续获奖、入学奖励等对招聘方有用的性质；名称未涵盖时简短补充。不把证书发证月份当作获奖学年，不编造评选标准或原因。
- 名称已完整表达内容且网站允许描述留空时可留空；必填时写简短真实说明，赛事可保留有来源的获奖作品。证书落款、截图日期、占位日等内部核对备注仅留在 `sourceText`，不写进网页描述。具体奖励范围由个人配置或本次确认决定。

## 跟进表更新

- 先确认实际工作簿路径、更新授权与状态口径；本机配置已记录时直接沿用，不重复询问。尚未授权或未同意口径时暂不更新，完成可独立进行的页面填写后集中交接。已授权的本轮记录更新是收尾动作，不仅提醒用户自行记录。
- 所有聊天统一调用 `python -B tools/update-job-tracker.py --workbook <工作簿> --request-file <请求JSON>`，见[更新契约](../../../docs/job-tracker.md)。按路径互斥、锁后重读再写入；不另写无锁脚本、用旧快照覆盖或重建替代表。只维护公司、岗位、完整真实超链接和状态，新增行继承序号与格式，其他列不主动补写或清空。默认不备份，仅用户明确要求时创建。
- 已完成页面填写并读回时传 `completed: true`，新记录或空状态写“筛选中”，不表示已提交。必填缺失、实质冲突或未验证写入时传 `false`，新记录状态留空；缺来源选填项正常留空不阻塞完成。保留旧笔试、面试等非空状态，不填未经确认的投递日期。
- 复用工具返回的工作表、行和读回结果，分别说明网页和跟进表是否完成，不重复渲染整表。占用、超时、外部改动、身份冲突或写入结果不明时保留网页成果，先核对实际记录，修正原因后通过同一入口恢复，不绕过锁。

## 报告与接管

- 保留 CLI 原报告及失败记录。`attempted` 只表示写入后读回与目标一致；`skipped_existing / readback: matched` 表示已有值匹配；`pending`、`unsupported`、`blocked`、`write_unverified` 不表示完成。命令成功不等于页面生效，未核对不当作正确，未保存不当作已保存。
- 汇总包含 `runId`、`tabId`、`tabReused`、`tabCreated`、`profileValidated`、`snapshotCaptured`、`snapshotRebound`、`reportVersion`、各项状态和 `userCheck`，按实际证据填写，未验证记未知。各项注明 `executionPath`、`routeReason`，`user.*` 保留 `sourceText`；发生恢复才记录失败原因、重试和路径切换。这些补充由 Agent 汇总，不声称现有 CLI 自动输出全部字段。
- 不为普通填写另建评测流程。用户要求比较速度或成本时，区分准备、执行、恢复、核对、等待与整体墙钟，并说明经验复用；没有 Token 或账单证据就记未知，不以调用次数换算费用。
